POLÍTICA DE PRIVACIDADE
Última atualização: junho de 2026

1. Responsável pelo Tratamento

Os dados coletados pelo Amor Revelado são tratados por Igor Ianov, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

Contato do responsável: ianov.igor@gmail.com

2. Dados Coletados

Coletamos os seguintes dados fornecidos pelo usuário no cadastro:

  • Nome completo
  • Data de nascimento
  • Cidade de nascimento
  • Endereço de e-mail

Também coletamos dados de uso, como consultas realizadas e plano ativo, para personalizar a experiência e calcular limites de uso.

Não coletamos dados de pagamento. Esses dados são processados diretamente pelas plataformas Stripe e Kiwify, com suas próprias políticas de privacidade.

3. Finalidade do Tratamento

Os dados são utilizados para:

  • Personalizar as leituras e consultas da Zara
  • Calcular o signo e informações astrológicas/numerológicas
  • Controlar o acesso conforme o plano contratado
  • Enviar comunicações sobre o serviço

4. Compartilhamento de Dados

Os dados do usuário não são vendidos ou compartilhados com terceiros para fins comerciais.

As consultas enviadas à inteligência artificial são processadas pela API da Anthropic, conforme a política de privacidade da empresa (anthropic.com). Nenhum dado pessoal identificável é enviado além do nome e signo do usuário para personalização das respostas.

5. Armazenamento e Segurança

Os dados são armazenados em servidores seguros. Adotamos medidas técnicas e organizacionais para proteger as informações contra acesso não autorizado.

6. Direitos do Usuário

Nos termos da LGPD, o usuário tem direito a:

  • Confirmar a existência de tratamento de seus dados
  • Acessar seus dados
  • Corrigir dados incompletos ou incorretos

  • Revogar o consentimento a qualquer momento

Para exercer esses direitos, entre em contato pelo e-mail ianov.igor@gmail.com.

7. Cookies

O Amor Revelado pode utilizar armazenamento local (localStorage) no dispositivo do usuário para manter preferências e dados de sessão. Não utilizamos cookies de rastreamento ou publicidade.

8. Menores de Idade

O Amor Revelado é destinado a maiores de 18 anos. Não coletamos intencionalmente dados de menores. Caso identifiquemos cadastro de menor, a conta será encerrada.
